# همراه‌پنل

یک داشبورد مدیریتی فارسی و راست‌چین بر پایه Next.js 16، React 19، Tailwind CSS 4 و HeroUI 3.

## امکانات

- پوسته روشن و تاریک با تشخیص تنظیم سیستم و ذخیره انتخاب کاربر
- رابط کاملاً RTL و محتوای فارسی
- سایدبار گروه‌بندی‌شده با جستجوی زنده و میانبر `Ctrl/Cmd + K`
- منوی موبایل، هدر واکنش‌گرا و اجزای HeroUI
- داشبورد نمونه شامل آمار، نمودار درآمد، فعالیت‌ها و پروژه‌ها
- متادیتا، viewport، TypeScript و ESLint آماده محیط production

## اجرا

```bash
npm install
npm run dev
```

سپس [http://localhost:3000](http://localhost:3000) را باز کنید.

## بررسی کیفیت

```bash
npm run lint
npm run build
```
